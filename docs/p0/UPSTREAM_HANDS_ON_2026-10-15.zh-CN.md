## A1：本地／远程模式快捷键（G13）

焦点位于本地 Bash 会话的主终端区域。

| 按键 | 观察结果 |
| --- | --- |
| Control + Return | 能在远程模式与本地模式之间切换 |
| Command + Return | 从远程模式测试，保持远程模式 |
| Shift + Return | 从远程模式测试，保持远程模式 |

这与发布包 `<Ctrl+Enter>` 绑定的静态线索一致，补充了 macOS 上实际物理按键的观察。结论只覆盖本轮焦点与模式；未验证其他控件焦点、normal／command 模式、用户自定义键位或 Windows/Linux。G13 的冻结验收文字若要修订，仍需同步功能矩阵、基线 Markdown 与 JSON，并通过结构验证。

## A2：SCP 入口查找（F08／F09，部分执行）

已观察的入口：

- 新建会话中的协议列表：Shell、SSH、Telnet、Tcp、Serial。
- 默认设置中的 SFTP 与 X/Y/ZModem 项。
- 会话菜单。

上述入口未见 SCP。**未检查连接远端后的文件面板右键菜单，也未检查拖放入口。** 因此只能记录“本轮已查入口未见 SCP”，不能推出产品没有 SCP，也不能据此删除或降低 F08／F09 的完整功能目标。

## A3：回滚行数设置（Q06）

入口：默认会话设置 → 窗口 → 回滚行。初始显示为 `999999`。

| 输入值 | 保存后重新打开的显示值 |
| --- | --- |
| `0` | `0` |
| `1000000` | `1000000` |
| `99999999` | `99999999` |

每项均保存、确认并重新打开设置读取；结束时恢复为 `999999`。本轮证明这些值能由该设置界面保存并读回，**没有执行相应容量的输出负载测试**。不能据此认定 `0` 表示无限，不能将 `99999999` 当作实际容量上限或证明内存、压缩、重排表现；“无限”选项的存在与语义也未取得确认。

## A4：退出后布局恢复（S08，部分执行）

建立本地会话标签 `P0-local-A` 与 `P0-local-B`，通过窗口菜单中的“垂直拆分视图”得到上下分屏，并隐藏文件面板。随后建立第二个窗口，再正常退出并重新启动。

| 检查项 | 观察结果 |
| --- | --- |
| A／B 标签 | 重启后恢复 |
| 分屏组 | 重启后恢复；本轮为上下分屏，未覆盖清单原定的左右分屏 |
| 隐藏文件面板 | 重启后仍隐藏 |
| 多窗口恢复 | 未确认 |
| 原有活进程恢复 | 未确认；标签或会话视图恢复不等于原 Shell 进程持续存活 |

本轮未覆盖停靠窗格移动后的具体位置恢复，也不证明所有布局组合或异常退出恢复可靠。
