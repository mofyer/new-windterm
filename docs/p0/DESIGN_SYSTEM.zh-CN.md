用户确认：浅色白银浮层方向已获认可；本轮用户另明确回复“沿这个中性炭灰方向继续”，认可新版深色方向。此记录仅确认视觉方向，不代表完整功能、性能或可访问性验收完成。

日期：2026-10-11。用户指定 [UI/UX Pro Max · Health & Wellness](https://www.uupm.cc/demo/health-wellness) 后的新实现，取代上一版 Graphite Studio。当前默认是近白画布、银白浮起面板和纯白终端，薄荷/绿色仅作强调；根据用户追加的“层次、圆角、干净通透”要求，替换了上一轮紧凑弱阴影方案。功能边界不变。

## 参考观察与技能应用

实际使用 Chrome 打开参考页面、查看截图并读取 computed CSS，观察到以下材质与层次：页面冷白/灰白 `#F5F5F5`、白色内容面板、深 slate 标题 `#2D3748`、次要文字 `#718096`、绿色 CTA `#22C55E`、薄荷与青色局部渐变；参考 `.neu-card` 为 24px 圆角，双向阴影 `8px 8px 16px rgba(174,174,192,.4), -8px -8px 16px rgba(255,255,255,.8)`；按钮则为 `4px 4px 8px` 同色阴影与反向白色高光，主 CTA 带绿色投影。最终实现采用这一层次强度，而非之前近乎不可见的投影。

已阅读本地 `ui-ux-pro-max/SKILL.md`，执行以下命令；`UI_UX_SKILL_ROOT` 指向已安装的 UI/UX Pro Max 技能根目录：

```sh
python3 "$UI_UX_SKILL_ROOT/scripts/search.py" \
  'health wellness soft ui clean mint white desktop professional' \
  --design-system -p 'New WindTerm Mint' -f markdown
```

结果命中 **Soft UI Evolution**，采纳柔和材质、明确层次、可见焦点、低强度动效与可访问性建议。自动输出的 lavender 色板和大标题/CTA 落地页结构不适用于用户指定参考与终端工具，因此色彩以真实参考页面为依据，结构保持桌面工作台。不是复制网页内容、健康主题或营销布局。

## 层次与布局

- 默认采用舒适布局：工具栏距窗口边缘 20px，高 64px、圆角 24px；工具栏与下面工作区间隔 20px，投影周围留有空间。
- 会话侧栏为独立浮起卡片，宽 240px、内边距 16px、圆角 24px，与终端区域相隔 20px。侧栏标题、搜索图标、会话状态点与分组标签共用距卡片内缘 12px 的同一列；会话行高 36px、间隔 4px、圆角 8px。侧栏搜索采用轻微内凹阴影，选中项用局部薄荷底。
- 主终端面板 24px 圆角、纯白内容区、银白标签区（48px）。活动标签为白色浮起小面，非活动标签为弱色文字，控件与文字不依赖四周边框分层。
- 文件检查器为终端内部独立银白卡片，16px 圆角、外留 12px、内边距 16px 和独立投影。传输队列为 16px 圆角浮起 dock，与终端相隔 12px。
- 工具栏次级按钮采用浅银材质与 4px 双向投影，按下状态为内凹；分屏/文件开关的开启态同样用中性内凹表示，不再染绿。主 CTA 为绿色实底，投影与其他按钮一致为中性。连接 sheet 为 24px 圆角，内凹输入框与浮起动作按钮。
- 桌面保持终端为主区域，不添加营销头或大标题。窗口宽度 ≤1100px 或高度 ≤700px 时，缩为 56px 工具栏、12px 外距、16px 列间距和 200px 侧栏，避免 1000×650 溢出。
- 用户可选紧凑模式：48px 工具栏、200px 侧栏、40px 标签、12px 外距；默认不会启用紧凑模式。
- 默认浅色终端用深蓝灰正文和较深的绿、蓝、红 ANSI 调色板。深色模式为中性炭灰，以低饱和青色作小面积强调，并独立切换 ANSI 色表与投影。
- Hover 不改变几何尺寸，过渡 140–160ms，弹窗进入 200ms，统一缓动 `cubic-bezier(.22, 1, .36, 1)`；减少动效偏好关闭所有过渡。截图需等待主题/对话框过渡结束。

## Carbon Dark 专项修订

用户认为原深青配色浑浊，因此深色主题改为中性炭灰。浅色白银方案与所有布局参数保持不变。再次应用 UI/UX Pro Max 设计搜索：

```sh
python3 "$UI_UX_SKILL_ROOT/scripts/search.py" \
  'professional desktop terminal neutral charcoal dark mode refined silver contrast restrained cyan' \
  --design-system -p 'New WindTerm Carbon' -f markdown
```

结果命中 Dark Mode / OLED；采纳低光环境对比度与可见焦点，不采用自动结果中的午夜蓝、荧光绿、发光文字或水平营销结构。

深色分三层：`#191B1E` 画布、`#22252A` 浮层、`#111315` 最深终端；活动标签/按钮另用 `#33373E`、`#2B2E33`，通过银灰轻边缘与阴影形成层次。面板投影是中性黑，顶部高光仅 4% 白，不再套用浅色大面积白色反向阴影。主按钮为低饱和青灰 `#A5C5CC` 搭配深字 `#192B31`；青色只用于动作与选中状态。

连接 sheet 为 `#25282D`，背景遮罩为近黑 `#07090C85`，消除青绿雾；输入框仍内凹。终端正文 `#DCE0E6`、黑底 `#111315`，ANSI 色表独立降饱和，避免荧光颜色。Unicode、PTY、输入和生命周期逻辑未调整。

- 深色连接 sheet：检查近黑遮罩、输入文字、主次动作与取消回到终端。

## 2026-11-07 去模板化打磨（unslop）

用户要求按 unslop 流程优化界面，并确认执行全部九项。本轮属于打磨：沿用上述已认可的浅色与深色方向、Avenir Next 字体、布局结构和双向柔和阴影，只修具体问题，不改变功能、安全提示或验收状态。

- **颜色**：主操作统一为一种绿 `#127143`（深色仍为 `#A5C5CC` 配深字）；移除主按钮绿色投影、toast 绿调阴影、弹窗绿雾遮罩（改为中性 slate `#2D374838`）、弹窗图标渐变和选中行彩色投影。强调色只保留在主操作、当前选中会话、会话状态点、进度条和焦点环；终端工具按钮、文件选中行、命令面板选中项、「查看边界」、连接弹窗入口改为中性色。新增中性 `--hover` / `--pressed` token，按钮 hover 不再整片薄荷。
- **字体**：字号收敛为 11/12/13/14/16/18px，最小 11px（原 10px 的状态栏、路径、徽标、传输摘要均上调）；字重只用 400/500/600；去掉品牌名与标题的负字距；全大写加字距的眉标改为普通大小写弱色小字。路径、文件大小、终端尺寸与计数使用 SF Mono / Menlo 等宽字并启用 tabular-nums。
- **图标**：图标抽为 `src/icons.ts` 单一集合，统一 1.5 描边、16px（弹窗标题图标 20px、标签关闭 14px）；新增文件与链接图标。标签页、文件行、SFTP 行与三个弹窗关闭按钮不再使用 `◌`、`›_`、`▸`、`↪`、`·`、`✕` 等文字字形。
- **标志细节**：会话状态点（8px，状态栏 6px）在标签、侧栏行与状态栏统一使用：实心强调色为真实会话，空心描边为演示，灰色为已结束。状态栏文字不再带 `●` / `◌` 前缀。
- **间距与圆角**：全部落在 4px 网格；圆角按层级为面板 24、卡片 16、控件 10、行 8、小控件 6、标签 4。
- **文案**：单句提示与说明去掉句号；命令面板占位符改为「搜索命令」；关于弹窗标题改为「原型能力与边界」；快捷键改为键帽样式；传输计数改为等宽数字。
- **布局**：连接弹窗的三个真实连接入口改为「桌面真实连接」分组下的列表行，id 与行为不变。

验证：前端 `npm run build` 通过；浏览器截图覆盖 1440×900 浅色/深色工作台、浅色连接 sheet 与 1000×650 深色，未见横向溢出，控制台 pageerror 为 0。本机全量浏览器 E2E 435 / 435 通过，含对比度测试，详见 [WEB_QA](WEB_QA.zh-CN.md#2026-11-07-去模板化打磨回归)。仍为浏览器演示与 IPC stub 结果，不代表原生 WebView、IME、读屏或完整可访问性验收。
