# P0 设计系统 · Silver Soft UI

日期：2026-10-11。用户指定 [UI/UX Pro Max · Health & Wellness](https://www.uupm.cc/demo/health-wellness) 后的新实现，取代上一版 Graphite Studio。当前默认是近白画布、银白浮起面板和纯白终端，薄荷/绿色仅作强调；根据用户追加的“层次、圆角、干净通透”要求，替换了上一轮紧凑弱阴影方案。功能边界不变。

## 参考观察与技能应用

实际使用 Chrome 打开参考页面、查看截图并读取 computed CSS，观察到以下材质与层次：页面冷白/灰白 `#F5F5F5`、白色内容面板、深 slate 标题 `#2D3748`、次要文字 `#718096`、绿色 CTA `#22C55E`、薄荷与青色局部渐变；参考 `.neu-card` 为 24px 圆角，双向阴影 `8px 8px 16px rgba(174,174,192,.4), -8px -8px 16px rgba(255,255,255,.8)`；按钮则为 `4px 4px 8px` 同色阴影与反向白色高光，主 CTA 带绿色投影。最终实现采用这一层次强度，而非之前近乎不可见的投影。

已阅读本地 `ui-ux-pro-max/SKILL.md`，执行以下命令；`UI_UX_SKILL_ROOT` 指向已安装的 UI/UX Pro Max 技能根目录：

```sh
python3 "$UI_UX_SKILL_ROOT/scripts/search.py" \
  'health wellness soft ui clean mint white desktop professional' \
  --design-system -p 'New WindTerm Mint' -f markdown
```

结果命中 **Soft UI Evolution**，采纳柔和材质、明确层次、可见焦点、低强度动效与可访问性建议。自动输出的 lavender 色板和大标题/CTA 落地页结构不适用于用户指定参考与终端工具，因此色彩以真实参考页面为依据，结构保持桌面工作台。不是复制网页内容、健康主题或营销布局。

参考的高亮绿色改为更深的 emerald，保证小号白色按钮文字可读；次要文字也比参考页加深。薄荷选中区域和绿色按钮只在局部使用，移除整片侧栏/画布的绿色染色。面板与控件使用参考强度的双向阴影，右下灰紫投影、左上白色高光，产生明显但柔和的浮起层次。

字体保持本机 Avenir Next、PingFang SC、Microsoft YaHei 回退，默认界面基准 **14px**，终端 SFMono-Regular / Menlo 14px / 1.45 行高。不加载远程字体或图标。工具栏主动作 13px，辅助标签与状态 10–12px。

## 层次与布局

- 默认采用舒适布局：工具栏距窗口边缘 20px，高 62px、圆角 24px；工具栏与下面工作区间隔 22px，投影周围留有空间。
- 会话侧栏为独立浮起卡片，宽 232px、圆角 24px。与终端区域相隔 22px。侧栏搜索采用轻微内凹阴影，选中项用局部薄荷底。
- 主终端面板 24px 圆角、纯白内容区、银白标签区。活动标签为白色浮起小面，控件与文字不依赖四周边框分层。
- 文件检查器为终端内部独立银白卡片，17px 圆角，外留 12–14px 和独立投影。传输队列为 17px 圆角浮起 dock，与终端相隔 14px。
- 工具栏次级按钮采用浅银材质与 4px 双向投影，按下状态为内凹；主 CTA 用绿色与绿色投影。连接 sheet 为 24px 圆角，内凹输入框与浮起动作按钮。
- 桌面保持终端为主区域，不添加营销头或大标题。窗口宽度 ≤1100px 或高度 ≤700px 时，缩为 54px 工具栏、12px 外距、16px列间距和198px侧栏，避免 1000×650 溢出。
- 用户可选紧凑模式：46px 工具栏、200px 侧栏、38px 标签、10px外距；默认不会启用紧凑模式。
- 默认浅色终端用深蓝灰正文和较深的绿、蓝、红 ANSI 调色板。深色模式为深青灰和薄荷强调色，并独立切换 ANSI 色表与投影。
- Hover 不改变几何尺寸，过渡 140–160ms；减少动效偏好关闭所有过渡。截图需等待主题/对话框过渡结束。
