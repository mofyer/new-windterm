## 交付原则

以 [功能对齐矩阵](FEATURE_PARITY.zh-CN.md)中的 ID 跟踪需求、实现、测试与差异。P0 盘点实际版本，澄清 README 与版本行为的矛盾；后续发现遗漏应补入基线，不得因为实现困难自行删减。上游尚未实现的路线图单独列为候选需求。

视觉方向采用现代苹果风，保留功能语义、安全与效率，允许重组入口和布局；不要求像素复刻。具体建议见[设计方向](DESIGN.zh-CN.md)，视觉验收与功能验收分别记录。

允许发布阶段性 alpha，但须公开未实现项；本地终端、SSH 或 SFTP 单独可用均不代表全量完成。全部基线功能在适用平台验收通过、差异有记录，才可宣称功能对齐完成；全部计划平台完成后才可宣称项目整体完成。macOS 上不存在的 Windows 管理员 shell 等能力在对应平台验收，不能当作永久排除项。

完整项目工期在 P0 的功能盘点、原型与风险分解后，结合实际人力重新估算。此前的基础功能工作量不能作为全量重构工期。当前[164 项剩余估算](p0/EFFORT_ESTIMATE.zh-CN.md)已按 53 包更新，并保留首版历史；它是人工规划估计而非日期承诺，按后续证据、路线与实际人员变化重估。

## 必须提前验证的风险

- **输入与显示**：中英文输入法组合态、emoji、宽字符、复制粘贴、选区、缩放和字体回退；记录设备、系统和输入法版本。
- **终端行为**：本地与 SSH 下的 vim、tmux、htop；光标、备用屏幕、颜色、鼠标、窗口缩放以及完整终端类型矩阵。不能把 xterm.js 的默认能力等同于 WindTerm 的全部终端兼容性。
- **性能与内存**：持续大量输出时队列有界、背压有效，不能静默丢数据；测量输入响应、CPU、内存、吞吐和历史检索。动态压缩属于待实现基线，压缩比例与资源预算由固定负载实测确定。
- **架构与依赖**：检查应用、动态库及所带运行组件的 arm64 支持，不依赖 Rosetta；核查许可证、维护状态、agent/GSSAPI/转发/tmux 能力并锁版本。
- **性能比较**：在固定硬件、系统、负载和数据集建立基线；不沿用上游旧机器数据作本项目承诺，不预设未经测量的“更快”或固定占用值。

## 安全与数据验收

以下是正式连接的验收目标；首次确认后保存、指纹一致复用、变化即阻断并需独立替换的主机信任已在 P0 原型实现（Ed25519，见[结果](p0/RESULTS.zh-CN.md)）；密码、带口令私钥与 agent 认证已有原型，RSA、keyboard-interactive、凭据安全保存与自动登录仍待实现。SSH 首次连接展示主机、端口、密钥类型和指纹，经明确确认后保存。已保存密钥变化时拒绝连接；更新信任需要独立用户操作。密码、公钥、带口令密钥、agent、keyboard-interactive 分别验证；GSSAPI 的上游版本差异先盘点再确定基线。界面区分连接中、已连接、认证失败、网络断开和已关闭。重连不自动重放此前输入；用户配置的认证后自动执行必须显式启用、明确显示，并定义重连是否执行。

秘密默认不保存；用户选择保存时，macOS 使用 Keychain，配置仅留引用。Windows/Linux 在平台阶段使用对应安全存储。日志、导出、崩溃报告和测试样本不得含密码、私钥或令牌。非秘密配置有版本、迁移、备份和失败恢复规则。

文件传输覆盖零字节、大文件、中文和空格路径、权限不足、网络断开、取消及同名覆盖。受控测试比较传输前后的大小和哈希，不假设任意 SFTP 服务端支持远端哈希接口。部分文件不得标为完成，失败后的残留状态必须可见。断点续传是否属于 2.7.0 基线须实测，当前不作未经核查的承诺。

WindTerm 迁移仅处理公开格式可识别的非秘密字段，使用脱敏 fixture、导入预览和跳过/重命名/明确替换的冲突策略，不修改源配置，不扫描无关目录，不解密旧凭据。凭据通过用户重新输入或安全存储授权建立；这项安全边界不影响对应认证功能的完整实现。

## 发行门槛

macOS 首要构建目标为 `aarch64-apple-darwin`，最低系统版本在 P0 确定：当前声明 13.3（见[发行包说明](p0/RELEASE.zh-CN.md)），尚未在旧系统实机验证。不提前宣称 macOS 28 已验证兼容。CI 构建通过不能替代真实 M 系列设备上的输入法、文件传输和完整功能验收。

对外分发需要 Apple Developer Program 对应权限、Developer ID 签名和公证；这些是待落实的依赖。候选包须验证新安装、启动、升级、配置迁移和回退限制。各平台安装包与证据齐备后才宣布对应版本可用。[Apple 公证说明](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)
