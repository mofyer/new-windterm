## 第一批：本地终端生命周期

状态：2026-10-15 已交付并合并 main，含 Unix 关闭资源顺序修复；记录提交 `bdcbb3e`，最终代码 CI 为 `645ed38`。完整 P1 尚未验收。

归属：[估算](../p0/EFFORT_ESTIMATE.zh-CN.md) A1 应用/终端边界与 A2 本地 Shell 的部分工作。当前启动失败后输入仍可能缓存，初次 resize 错误可能覆盖退出状态；正常退出没有明确恢复入口。

交付范围：

1. 启动失败成为明确终态，停止接收输入并清空启动前队列。
2. 初次 resize 失败与启动失败区分，异步错误不得覆盖已退出/已销毁状态。
3. 已退出或启动失败时提供“重新打开本地终端”，创建全新会话，保留旧输出；不复用旧事件通道，不自动重放旧输入。
4. 提示当前终端已结束、输入不会发送，正常运行时不展示误导性恢复操作。

验证：浏览器 IPC 契约覆盖失败、退出、重复点击、输入不重放、resize/exit 竞态和既有关闭行为；Linux/Windows 原生 WebView 场景扩充真实退出码、重新打开和 shell 输出读回。浏览器契约不代表原生通过；macOS 完整原生、IME/读屏和性能仍需对应交付验收。

本批不改变 Shell 启动参数、持久设置、主题和传输功能，不声明 T01/T34 或 A1/A2 整包完成。产品代码修改经独立审查、合并后本机门禁及跨平台 CI；不修改冻结台账状态。

## 第二批：T34 启动目录（2026-10-18 开始）

状态：本机门禁与三端有限原生验收完成，修正后的跨平台 CI 7/7 通过；2026-10-18 已获用户单独批准，main 从 `bdcbb3e` 快进至 `cf700c2` 并推送。随后仅补合并记录，分支最终 SHA 以远端 refs 为准。执行与限制见 [RESULTS](RESULTS.zh-CN.md#2026-10-18第二批-t34-启动目录)。

本批只交付启动目录配置，不扩展为启动命令、环境变量、locale 或持久化会话配置。

1. 保留一键默认本地终端入口，增加显式启动目录输入；留空使用现有默认目录。
2. Rust 按当前平台校验绝对路径和目录，直接传入进程创建参数，不展开变量或 `~`，不拼接 shell 命令，不改变应用全局工作目录。校验时无效的目录必须报错。锁定的 portable-pty 0.9.0 会对失效 cwd 回退到 HOME/USERPROFILE，因此创建前再次校验；外部进程恰在最后校验与库内检查之间删除或改名的竞态仍需明确记录，不能宣称已彻底消除。
3. 目录字符串中的合法空格及中文原样传递；Windows 相对盘符路径、根相对路径及当前 cmd.exe 不支持的目录形式明确报错。
4. 重新打开继承原会话的启动目录，创建新的 PTY；随后编辑表单不能改变已有会话的启动配置。
5. 浏览器测试证明输入与 IPC/重新打开契约；真实 PTY 和 Linux/Windows 原生 WebView 读回 shell 的实际目录，覆盖退出后重新打开。两类证据分别记录。

并行职责：`p1/cwd-backend` 负责 Rust 校验与 IPC；`p1/cwd-ui` 负责界面、会话配置及浏览器契约；`p1/cwd-native` 负责真实 PTY/原生场景。协调者负责独立审查、集成、全套门禁与 CI。全部通过后取得本批单独批准并合入 main，未沿用第一批批准。

## 第三批：Shell 发现、选择与缺失反馈（2026-10-18 开始）

起点为已合并的 `8823be4`。后端、界面与真实 PTY/原生验收在三个隔离 worktree 并行实施，已完成独立代码审查、本机集成门禁及 macOS 单轮原生验收；`68808de` 已推送并触发本批 CI，跨平台最终验收与 main 合并批准仍待完成。

1. 发现当前平台常见安装位置的 Shell：macOS/Linux 的 Bash、zsh、PowerShell 7；Windows 的 cmd、Windows PowerShell、PowerShell 7。只检查文件，不因打开选项而执行程序；不扫描用户目录，不声称覆盖任意安装位置。
2. 前端仅提交固定 Shell ID，路径由后端解析。缺省维持原有平台默认行为；明确选择的 Shell 缺失、不可执行或不适用于当前平台时反馈错误，不静默换成其他 Shell。
3. 每个会话保存 Shell 选择和启动目录，重新打开继承两者；修改表单不影响已有会话。发现失败、不可用选项和异步发现竞态有独立反馈。
4. 保留受控启动参数和环境，不增加自由命令字符串、用户 rc/profile、参数/env/locale 编辑或持久设置。Windows 既有目录限制继续保留，不据此推断 PowerShell 自身不支持这些路径。
5. 浏览器验证 IPC/选择/重开契约；真实 PTY 与原生 WebView 分别验证 Shell 身份、实际目录、退出及重开。macOS 优先显式 Bash，Windows 验证 Windows PowerShell，Linux 验证显式 Bash；缺失的可选 Shell 不标为通过。

产品代码按既有全套门禁与跨平台 CI 验证，三端结果分别记录；本批合并 main 前另行请求确认。
