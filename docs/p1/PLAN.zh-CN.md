## 第一批：本地终端生命周期

归属：[估算](../p0/EFFORT_ESTIMATE.zh-CN.md) A1 应用/终端边界与 A2 本地 Shell 的部分工作。当前启动失败后输入仍可能缓存，初次 resize 错误可能覆盖退出状态；正常退出没有明确恢复入口。

交付范围：

1. 启动失败成为明确终态，停止接收输入并清空启动前队列。
2. 初次 resize 失败与启动失败区分，异步错误不得覆盖已退出/已销毁状态。
3. 已退出或启动失败时提供“重新打开本地终端”，创建全新会话，保留旧输出；不复用旧事件通道，不自动重放旧输入。
4. 提示当前终端已结束、输入不会发送，正常运行时不展示误导性恢复操作。

验证：浏览器 IPC 契约覆盖失败、退出、重复点击、输入不重放、resize/exit 竞态和既有关闭行为；Linux/Windows 原生 WebView 场景扩充真实退出码、重新打开和 shell 输出读回。浏览器契约不代表原生通过；macOS 完整原生、IME/读屏和性能仍需对应交付验收。

本批不改变 Shell 启动参数、持久设置、主题和传输功能，不声明 T01/T34 或 A1/A2 整包完成。产品代码修改经独立审查、合并后本机门禁及跨平台 CI；不修改冻结台账状态。
