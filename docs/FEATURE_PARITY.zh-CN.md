# WindTerm 完整功能对齐矩阵

基线：WindTerm 2.7.0 实际行为。下表从[该版本 README](https://github.com/kingToolbox/WindTerm/blob/a8336c1d1e3dd1a981500dae8ef9eb42066de95f/README.md#features)逐项展开，尚未完成上游实机盘点；README 描述不能代替行为验收。每项测试记录应包含 ID、上游步骤与结果、本项目步骤与结果、平台、版本和证据。目前尚无条目完成全项对齐验收；已有局部 UI 与真实本地 PTY 原型，见[P0 结果](p0/RESULTS.zh-CN.md)。

对齐要求覆盖功能语义、安全与操作效率，不要求旧界面像素一致。采用[现代苹果风设计](DESIGN.zh-CN.md)，新入口映射到现有功能 ID，保持可搜索、可键盘触达；不得以视觉简化为由隐藏或删除能力。功能验收与视觉验收分别记录，本次不更改下列 117 个 ID。

下表保留初始规划状态：“未实现”表示尚未交付可按该行完整验收的功能；“待实测”表示上游文档存在冲突或能力边界尚不明确。局部原型不将整行标为完成。证据分为产品实测支持、文档宣称或矛盾待核、路线图未确认三类；P0 的有限入口观察另记于[基线台账](p0/BASELINE.zh-CN.md)，不因出现在路线图就认定产品没有该功能。P0 将补充版本实际具有但文档遗漏的功能。阶段对应[实施路线](ROADMAP.zh-CN.md)，不是删减范围；P5 对所有适用平台重新验收。

## 文档冲突与上游未实现路线图

[上游 2.7/2.x 路线图](https://github.com/kingToolbox/WindTerm/blob/a8336c1d1e3dd1a981500dae8ef9eb42066de95f/README.md#roadmap-of-v27-february-2025-for-reference-only)将 GSSAPI、命令片段和会话搜索列为延期，其中 GSSAPI 又出现在功能支持声明中。GSSAPI 和会话搜索保留待实测项，不擅自宣称已有或删除。

Mosh、Rlogin、FTP、FTPS、外部工具、聊天模式、日志查看器、脚本、宏和插件系统属于上游路线图候选，不能直接标为 2.7.0 已实现能力。命令片段也先作为延期候选。Auto Complete 同时出现在功能与路线图中，已作为 G02 保留，具体行为待实测。实机若确认候选中某项已存在，应补入基线并赋予独立 ID；否则后续另行排期。用户要求的“完整重构”针对已有功能，不能用这些候选替代已有功能的验收。

## 本项目必要的补充验收

上述对齐之外，还必须完成中文 IME、凭据安全存储、配置版本迁移、非秘密 WindTerm 配置导入预览与冲突处理、arm64 运行依赖、签名公证、安装升级和回退测试。详见[实施路线](ROADMAP.zh-CN.md)。不解密旧凭据；用户可重新提供凭据以恢复对应认证功能。
